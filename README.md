# MONOLITH — Architecture & Construction

A responsive, static portfolio website concept for an architecture, construction, and interior design company. Created as a demonstration website for a web-design portfolio.

## Files
- `index.html` — page structure and content
- `styles.css` — responsive layout, typography, interactions and styling
- `script.js` — mobile navigation, project filters and project-detail modal
- `hero-residence.jpg`, `project-interior.jpg`, `villa-study.jpg`, `project-detail.jpg` — locally bundled visual assets
- `monolith-mark.svg` — brand mark

## Local preview
Open `index.html` in a modern browser.

## Cloudflare Pages
This is a static website. Connect the GitHub repository to Cloudflare Pages with framework preset `None`, build command `exit 0`, build output directory `.` and production branch `main` (or the actual default branch in the repository).

## Demo note
Monolith and its projects are fictional portfolio concepts. The contact action opens an email draft. Project cards, category filters and the navigation are interactive. The displayed project counts and project information are illustrative, not verified business claims.
